# Лабораторная работа 5. Обработка строк

## Как запустить
`python normalize.py`, `python palindrome.py`, `python replace.py`, `python variant.py`.

---

## 1. Нормализация (`normalize.py`)
| Ввод | Ожидаемый результат |
|---|---|
| `Один   два` | `Один два`, слов 2, длина 8 |
| пустая строка | длина 0, слов 0 |

## 2. Палиндром (`palindrome.py`)
| Ввод | Ожидаемый результат |
|---|---|
| `А роза упала на лапу Азора` | Палиндром |
| `а` | Палиндром |
| строка из пробелов | Нет текста |
| `Python` | Не палиндром |
| `А!` | Не палиндром |

## 3. Замена (`replace.py`)
| Ввод | Ожидаемый результат |
|---|---|
| `a::b:` | замен 3, результат `a--b-` |
| `abc` | замен 0, без изменений |

## 4. Вариант 6 (`variant.py`) — длина равна 4
Контрольный текст: `Анна, армия! Я читаю. Книга, край, рама..`

| Вход | Ожидаемый результат |
|---|---|
| контрольный текст | анна, край, рама; количество 3 |
| пустой ввод | Нет совпадений, количество 0 |
| `!!!` | Нет совпадений, количество 0 |
